# Pattern: adoption-event RSVP blast

**Trigger.** Adoption event Saturday at the pet-store venue; blast goes out
Tuesday-ish (T-4/T-5).

**Blast (general coordinator).**
- Subject: attention prefix + save-the-date + event date.
- Body beats: you're receiving this because your foster dog (or one you're
  picking up soon) is on the event list; if not adopted before then, they'll
  be there; reply to confirm receipt and attendance; invitations to attach
  requests to the reply — nail trim, "check something out" about the dog,
  supplies available at the safehouse (ask if you can't find things);
  starred clause: if you have an adoption appointment before Saturday and it
  goes through, disregard this.

**Replies (dozens, over 2–3 days, same thread).**
- One-liners naming dogs: "{Dog} will be there", "Confirming to drop {Dog}
  and {Dog} if not adopted before then".
- Some add the invited requests (nail trim, look-at-this asks).
- Register ranges from telegraphic (no greeting, no sign-off) to chatty.

**Side patterns.**
- Forgot-to-add: a personal `Fwd:` minutes after the blast, apologizing and
  naming the recipient's dog.
- Stragglers get a short nudge near the deadline.

**Shape.** 30+ messages in one thread is normal at ~25–40 invited fosters;
replies cluster in the first two hours, then trickle.
