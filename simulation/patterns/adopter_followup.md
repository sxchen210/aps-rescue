# Pattern: adopter follow-up (alumni)

**Trigger.** A past adopter writes weeks/months after adoption: a happy
update plus a request.

**Opener (adopter).**
- Milestone anecdote first (settling in, first vet visit went well).
- Rename note: "{OldName} (aka \"{NewName}\" now)".
- The ask: photos from the dog's old adoption listing, records, advice.
- High-enthusiasm register, double exclamation marks, signs full name.

**Coordinator reply.**
- Warm, references the dog by old name naturally.
- Tooling-limit workaround narrated honestly ("files are too large for the
  shared mailbox — I'll send from my own account" / shares a drive link).
- Signs first name.

**Troubleshooting loop (0–3 turns).**
- Access denied → "requested access!" → "Oh weird, let me try another
  way…" → resolution → "It worked! Thank you!!".

**Shape.** 3–5 messages across a single day; both sides warm; no state
stakes beyond goodwill (dog is already adopted) — good background noise that
exercises dog-identity continuity (old name ↔ new name).
